# PROJETO FLEXTECH

Este repositório é destinado exclusivamente ao desenvolvimento da landing page da Flextech, cujo produto principal é a "Joelheira Ortopédica de Fibra de Cobre".

## 1. REGRA DE SEGURANÇA DO PROJETO

- Trabalhar somente dentro deste repositório.
- Nunca modificar o projeto antigo "turboclean-site".
- Nunca alterar outro repositório GitHub.
- Nunca alterar DNS, Cloudflare, Workers, domínios ou configurações de hospedagem sem autorização explícita.
- Nunca apagar arquivos ou funcionalidades importantes sem autorização.
- Antes de executar uma alteração potencialmente destrutiva, explicar o que será alterado e solicitar autorização.
- Não publicar/deployar alterações sem autorização explícita.
- Não expor, criar ou solicitar credenciais, tokens, senhas ou chaves secretas.
- Nunca colocar informações sensíveis diretamente no código.

## 2. OBJETIVO

Criar uma landing page de alta conversão para venda da Joelheira Ortopédica de Fibra de Cobre Flextech.

O projeto deve priorizar:
- conversão;
- confiança;
- clareza;
- experiência mobile;
- velocidade;
- acessibilidade;
- SEO básico;
- boa experiência de compra;
- aparência profissional.

## 3. DESIGN

A página deve seguir uma abordagem Mobile-First.

A experiência visual deve lembrar um aplicativo moderno quando visualizada no desktop, com conteúdo centralizado e largura controlada.

Referência estrutural de estilo:
https://imovis.com.br/legfix-desconto/

Não copiar conteúdo, código, imagens ou identidade visual de terceiros.

### Identidade visual

- Fundo principal: branco/ice.
- Texto principal: Navy Dark #0a192f.
- Detalhes e destaques: Orange #ff7b00.
- CTA principal: Vibrant Green #25D366.
- Bordas e cartões: visual limpo, moderno e arredondado.
- Evitar excesso de elementos visuais.
- Priorizar contraste e legibilidade.

## 4. MOBILE-FIRST

A maior prioridade é a experiência em smartphones.

A página deve:
- funcionar perfeitamente em telas pequenas;
- ter botões grandes e fáceis de tocar;
- evitar textos excessivamente pequenos;
- evitar elementos que causem rolagem horizontal;
- manter CTAs importantes visíveis;
- ter espaçamento confortável;
- carregar rapidamente.

No desktop, manter a experiência centralizada, semelhante a uma aplicação, com largura máxima aproximada de 500px quando isso fizer sentido para a composição.

## 5. CTA

Os botões de conversão devem utilizar a identidade definida para CTA.

Cor principal:
#25D366

Os CTAs podem utilizar uma animação CSS sutil de "pulse" contínuo, desde que não prejudique acessibilidade ou performance.

Sempre respeitar:
prefers-reduced-motion.

## 6. CRO

A estrutura da landing page deve seguir princípios de CRO.

Priorizar:
- proposta de valor clara;
- benefício principal rapidamente compreendido;
- prova social;
- redução de objeções;
- apresentação clara do produto;
- benefícios;
- diferenciais;
- garantia;
- segurança;
- informações de pagamento;
- frete;
- FAQ;
- chamadas para ação distribuídas estrategicamente.

Não criar alegações médicas não comprovadas.

Não prometer cura, tratamento ou resultados garantidos.

Qualquer afirmação relacionada à saúde deve ser tratada com cuidado e baseada somente em informações fornecidas pelo proprietário do projeto ou fontes autorizadas.

## 7. IMAGENS E ASSETS

Não inventar imagens reais do produto quando houver assets oficiais disponíveis.

Preservar a aparência real da Joelheira Flextech.

Não substituir automaticamente imagens oficiais por imagens genéricas ou geradas por IA.

Não alterar logotipos, embalagem ou características físicas do produto sem autorização.

O projeto deverá organizar os assets de forma clara.

## 8. RESPONSIVIDADE

Testar a página em pelo menos:
- smartphone pequeno;
- smartphone moderno;
- tablet;
- desktop.

Evitar layout quebrado, overflow horizontal ou elementos cortados.

## 9. ACESSIBILIDADE

Utilizar:
- HTML semântico;
- alt text apropriado;
- contraste adequado;
- foco visível;
- navegação por teclado quando aplicável;
- aria-label somente quando necessário;
- respeito a prefers-reduced-motion.

## 10. PERFORMANCE

Priorizar:
- imagens otimizadas;
- lazy loading quando apropriado;
- pouco JavaScript desnecessário;
- CSS eficiente;
- evitar bibliotecas pesadas sem necessidade.

## 11. CÓDIGO

Manter código:
- organizado;
- legível;
- modular;
- reutilizável;
- simples de manter.

Não adicionar dependências sem necessidade.

Antes de instalar uma nova biblioteca, avaliar se a funcionalidade pode ser feita com HTML, CSS ou JavaScript nativo.

## 12. GIT

Manter commits pequenos e descritivos.

Não fazer commits gigantes contendo alterações não relacionadas.

Antes de um commit importante:
- verificar arquivos modificados;
- verificar o diff;
- executar testes/verificações disponíveis.

Nunca usar comandos destrutivos do Git sem autorização explícita.

## 13. PROCESSO DE DESENVOLVIMENTO

Antes de executar tarefas grandes:
1. analisar o projeto;
2. explicar brevemente o plano;
3. identificar possíveis riscos;
4. executar a alteração;
5. testar;
6. revisar o resultado;
7. informar o que foi alterado.

Não assumir requisitos que não foram definidos quando isso puder afetar conversão, funcionamento ou identidade visual.

## 14. REGRA PRINCIPAL

Quando houver dúvida entre:
- alterar;
- apagar;
- substituir;
- instalar;
- publicar;

preferir perguntar antes de realizar uma alteração potencialmente importante.

O objetivo é construir a landing page Flextech de forma profissional, segura, controlada e orientada à conversão.
